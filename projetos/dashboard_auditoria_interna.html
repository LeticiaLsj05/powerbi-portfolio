🏭 Auditoria Industrial

Dashboard Power BI

Monitoramento de auditorias e indicadores de controles internos.

🎯 Objetivo

Desenvolver um dashboard para acompanhar auditorias internas e externas, consolidando indicadores em um único ambiente para apoiar a tomada de decisão.

📊 Indicadores

✔ Resumo do período
✔ Movimentações diárias
✔ Participação por item (%)
✔ Ranking de item (qtde)
✔ Top itens (qtde x valor)

🛠 Tecnologias

✔ Power BI
✔ DataSheet
✔ Scheduled Refresh
✔ DAX
✔ Power Query

🚀 Desafios

• Integração com atualização automática (Scheduled Refresh)
• Modelagem do banco web
• Desenvolvimento em DAX
• Organização do layout executivo
