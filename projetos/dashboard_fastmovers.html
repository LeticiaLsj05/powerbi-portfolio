🏭 Fast Movers

Dashboard Power BI

Monitoramento dos maiores itens fast movers.

🎯 Objetivo

Desenvolver um dashboard para acompanhar os itens com maiores movimentações de estoque, entender como isso impacta tanto em valor quanto produção e a partir disso gerar insights valiosos para a tomada de decisão.

📊 Indicadores

✔ Resumo do período
✔ Movimentações diárias
✔ Participação por item (%)
✔ Ranking de item (qtde)
✔ Top itens (qtde x valor)

🛠 Tecnologias

✔ Power BI
✔ Python
✔ Excel
✔ DAX
✔ Modelo Semântico
✔ Datamart
✔ Power Query

🚀 Desafios

• Tratamento dos dados com Python
• Modelagem do banco via datamart e modelo semântico
• Desenvolvimento em DAX
• Organização do layout
